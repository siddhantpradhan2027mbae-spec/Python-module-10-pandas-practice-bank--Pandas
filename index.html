Try each one in VS Code first, then check yourself against the expected output.

Before you touch the data

  1. What are the rows? What are the columns?
  2. Which columns are numbers, which are text?
  3. Any missing values I should expect?
  4. Do I need one column, one row, or a slice?

Picking the right tool

  • loc = labels, iloc = positions
  • One statistic per group? groupby + sum/mean
  • A grid of two categories? pivot_table or crosstab
  • Combining two tables? merge (keys) or concat (stack)

Before you trust the output

  1. Check .shape after every big step
  2. Print .dtypes, do not assume a type
  3. isna().sum() before and after cleaning
  4. Read the output, does it even make sense?
Stuck? Run print(df.head()) and print(df.dtypes) before writing any logic. Most pandas bugs are a wrong column name or a column that is text when you expected a number. Print the DataFrame after every single step, not just at the end, so you can see exactly where it went wrong.
